Система контроля доступа с RFID и распознаванием лиц.

## Как работает система (схема)

 1. Сотрудник
    1.  карта / лицо
    
 2. Турникет (считыватель + камера)
    1.  HTTP-запрос: "card_id" или "фото"
    
 3. API (FastAPI):
    1. "разрешено" -> турникет открывается
    2. "отказ" -> турникет закрыт
    3. пишет событие в журнал (access_logs)

Кто что может:

| Действие | admin | security | employee |
|---|---|---|---|
| Создавать и блокировать сотрудников, карты, точки доступа, устройства | да | нет | нет |
| Смотреть сотрудников, карты, точки доступа, журнал | да | да | нет |
